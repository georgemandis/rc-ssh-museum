# submit artwork
Submissions are handled directly from the gallery.
SSH in and press u to submit your work.
$ ssh mussheum.rcdis.co
# you'll be prompted for a title, artist name, image URL,
# an optional statement, and an optional artist URL.
# your submission opens a pull request for review.
# you must be a Recurse Center member to submit.
